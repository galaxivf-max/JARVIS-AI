# 🤖 J.A.R.V.I.S.

> **Just A Rather Very Intelligent System.** Il tuo assistente personale, ovunque tu sia.

JARVIS non è una semplice web app. È un ecosistema nato per trasformare il tuo telefono in un vero assistente AI autonomo, con tracciamento GPS in tempo reale, controllo vocale e interfaccia nativa.

### ✨ Cosa fa

- **🧠 AI Conversazionale:** Parla con JARVIS come faresti con una persona reale.
- **📍 GPS Live Tracking:** Localizzazione in tempo reale direttamente dal tuo telefono.
- **📱 PWA Nativa:** Installabile su Android e iOS come un'app vera, senza App Store. Funziona offline.
- **⚡ Leggero e Veloce:** Zero bloatware. Solo `web/` + Python. Pesa meno di 20MB.
- **🔓 Open Source:** Tutto il codice è qui. Modificalo, miglioralo, fallo tuo.

### 📲 Installazione in 10 secondi

**Android:**
1. Scarica l'ultimo `JARVIS.apk` dalla sezione [Releases](../../releases)
2. Installa sul telefono
3. Fatto.

**iPhone (senza App Store):**
1. Apri il link della Live Demo su Safari
2. Condividi -> Aggiungi a schermata Home
3. Avrai l'icona di JARVIS come app nativa.

**PC:**
```bash
# Clona il repo
git clone https://github.com/TUO_NOME/JARVIS.git
cd JARVIS

# Avvia il core
python main.py
